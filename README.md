## 🧪 Projects

**Predicting-Temperature-in-London**
Built and compared multiple machine learning regression models to predict mean daily temperature in London from historical weather data. Experiments were tracked and compared with MLflow.

**crop-recommendation-ml**
A classification project that predicts the most suitable crop from soil nutrients, weather conditions and pH values, supporting smarter, data-driven farming decisions.

**End_to_End_Machine_Learning-And-Web_GUI_Pipeline**
A complete end-to-end capstone that predicts the total purchase amount of retail transactions from customer demographics and product information. It covers everything from raw data cleaning to a live, interactive web application.

**investigating-netflix-movies**
An exploratory data analysis completed on DataCamp, using Python to analyze and visualize trends in 1990s cinema.

**Factors Affecting Computer Science Student Population (SWEP 200 Project, OAU)**
A team research project I worked on as a data analyst from August to September 2025. I collected and structured survey and academic data, analyzed enrollment trends with Pandas and NumPy, and identified key drivers such as workload, admission patterns and facility availability. We then proposed data-driven recommendations for balancing the student population and presented our findings to project supervisors.

### How I like to contribute

1. **Find** a beginner-friendly issue (`good first issue` or `help wanted`)
2. **Read** the contributing guide and get to know the codebase first
3. **Discuss** my approach with the maintainers before making big changes
4. **Build** a small, focused change with a clear commit message
5. **Open** a well-described pull request
6. **Learn** from the review feedback and improve
